# quad_perception (Phase 3, stub)

Sensor bridging (depth camera or LiDAR from Gazebo via `ros_gz_bridge`), frame
conversion from PX4 NED/FRD to ROS ENU/FLU, and RTAB-Map launch and configuration
for live mapping.

Not a ROS package yet, so colcon skips it.
